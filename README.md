# CatalyX OS

A modular Debian-based Linux distribution focused on Cloud, Security, DevOps, and system administration.

## Project Status

🚧 Active Development

## Current Features

- Modular CLI architecture
- System information and diagnostics
- Network diagnostics
- Cloud tooling detection
- Security diagnostics
- DevOps tooling detection
- Package management
- Configuration-driven OS identity

## Architecture

CatalyX is being developed as a modular Linux distribution built on a Debian base.
